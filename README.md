# IRONPULSE — STRENGTH MEETS SCIENCE
### AI-Powered Fitness & Wellness Intelligence Ecosystem

IRONPULSE is a premium, modern, fully responsive fitness technology web application built with **React.js**, **Vite**, **Tailwind CSS**, **Recharts**, **Lucide React**, and **Framer Motion**.

## 🚀 Key Modules & Routes

| Route | Page | Key Features |
|---|---|---|
| `/` | **Home** | Hero section with dark overlay, animated stats, discipline cards, value pillars, featured workouts, transformation stories, blog previews, and global search trigger. |
| `/workouts` | **Workout Library** | Filterable by 8 muscle groups, difficulty, equipment, and text search. Includes comprehensive modal guides (instructions, tips, mistakes) and favorite bookmarks. |
| `/planner` | **Interactive Workout Planner** | 7-day scheduler, 1-click loaders for Push Pull Legs (PPL), Bro Split, Upper/Lower, and Full Body splits. Set, rep, and weight logging, completion streaks, and built-in Rest Interval Stopwatch with audio alerts. |
| `/ai-coach` | **PULSE-AI Coach** | Conversational sports science AI simulation with quick prompt shortcuts, fitness goal selectors, and structured recommendation cards. |
| `/workout-generator` | **AI Workout Generator** | Personalized form collecting age, gender, height, weight, experience, facility (Gym/Home), and frequency. Compiles tailored splits with 1-click export to active planner. |
| `/nutrition` | **Nutrition & Diet Tracker** | Daily calorie & macro target bars, Recharts donut distribution chart, 6-meal logging windows, searchable food database (paneer, soya chunks, whey, lentils, etc.), and curated diet blueprints. |
| `/diet-generator` | **AI Diet Plan Generator** | Custom nutrition calculator accounting for dietary preference (Veg, Non-Veg, Vegan, Eggetarian), meal counts, and Indian food staples. |
| `/calculators` | **8 Scientific Calculators** | 1. BMI, 2. BMR (Mifflin-St Jeor), 3. TDEE, 4. Protein, 5. Daily Calorie & Macros, 6. U.S. Navy Body Fat %, 7. Ideal Weight, 8. Water Intake. |
| `/progress` | **Progress Tracker** | Recharts weight progression line chart, weekly training volume bar chart, body circumferences tracker, and before-and-after photo upload preview. |
| `/activity` | **Daily Activity Telemetry** | Steps gauge (target 10,000), calories burned, walking distance, active minutes, hourly step cadence chart, and nocturnal sleep architecture breakdown. |
| `/blog` & `/blog/:id` | **Fitness Science Blog** | In-depth research articles covering progressive overload, protein distribution, creatine monohydrate, sleep biology, spot reduction myths, and deadlift mechanics. |
| `/community` | **Community Hub** | Athlete discussion feed, live like counters, real-time comments, 30-day challenges, weekly leaderboard tiers, and achievement badges. |
| `/profile` | **Athlete Profile** | Personal biometrics, membership badges, streak counters, and pinned favorite exercise library. |
| `/login` & `/signup` | **Authentication UI** | Simulated authentication with LocalStorage persistence and 1-click demo login autofill. |
| `*` | **404 Not Found** | Custom futuristic recovery screen with navigation shortcuts. |

## 🛠️ Technology Stack

- **Framework:** React 18 (Vite)
- **Styling:** Tailwind CSS + PostCSS + Autoprefixer
- **Charts:** Recharts
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Persistence:** HTML5 LocalStorage

## 💻 Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run local development server:
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   ```

4. Preview production build:
   ```bash
   npm run preview
   ```
